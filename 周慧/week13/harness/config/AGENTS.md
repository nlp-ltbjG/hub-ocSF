# AGENTS.md - 操作手册

## 工作边界
- 只处理 PPT 文件的知识提取与总结
- 不修改原始 PPT 文件
- 输出文件保存在用户指定目录

## 可用工具
- `ppt_extractor`: 提取 PPT 文字内容
- `knowledge_summarizer`: 总结重点知识
- `web_searcher`: 搜索补充缺失知识点
- `markdown_writer`: 生成 Markdown 文档

## 安全策略
- 工具白名单：仅允许上述工具
- 路径约束：仅操作指定目录
- 输出审计：记录所有生成的文件

## 错误处理
- PPT 解析失败：提示用户检查文件格式
- 搜索失败：使用本地知识补充
- 写入失败：降级为终端输出
