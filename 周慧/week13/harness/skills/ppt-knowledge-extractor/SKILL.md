# ppt-knowledge-extractor Skill

## 元数据
- **版本**: 1.0.0
- **创建时间**: 2026-07-28
- **依赖**: python-pptx

## 触发条件

当用户输入包含以下关键词时触发：
- ppt, pptx, 幻灯片, 课件
- 提取PPT, 总结PPT, 课件解析
- "帮我看看这个PPT", "分析这份课件"

## 执行流程

### 阶段 1：PPT 文字提取

1. 解析用户提供的 PPT/PPTX 文件路径
2. 使用 `python-pptx` 遍历每一页，提取所有文本
3. 处理格式：清理空白、按页组织
4. 支持批量处理多个文件

### 阶段 2：知识总结

根据提取内容，生成结构化总结：

1. **核心概念提炼**: 术语定义、关键公式
2. **架构模型梳理**: 分层结构、组件关系
3. **技术对比分析**: 优劣对比、适用场景
4. **最佳实践归纳**: 设计原则、经验总结
5. **应用场景列举**: 典型案例、实战参考

### 阶段 3：补充缺失知识

识别知识盲区并主动搜索补充：

1. 检查基础术语是否已解释
2. 检查技术背景是否已覆盖
3. 使用 WebSearch 补充缺失内容
4. 标注信息来源

**搜索策略**:
- `AI Agent 入门教程 {topic} 详解 2025`
- `{topic} 原理 入门 教程 2025`
- `{topic} 选型 对比 最佳实践`

### 阶段 4：生成文档

输出结构化 Markdown 文件：

```
# [主题] 核心知识体系总结

## 一、基础概念补充
## 二、核心内容总结
## 三、架构与模型详解
## 四、概念辨析与对比
## 五、补充知识点
## 六、学习路径建议
```

## 输出契约

1. 文件命名: `[主题]_[YYYYMMDD_HHMMSS].md`
2. 保存位置: `week13/result/` 目录
3. 编码格式: UTF-8 Markdown
4. 包含来源标注和生成时间
